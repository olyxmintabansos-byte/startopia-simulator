An authentic pixel-art Growtopia **Startopia Mission Trainer & Simulator** designed to help Captains master star tool sequences, train reflexes, and eliminate voyage mistakes before risking real in-game Galactic items.

---

## ✨ Features

- 🛸 **All 12 Star Tools:** Tactical Drone, Teleporter, Q-Scanner, Stellar Documents, Cyborg Diplomat, AI Brain, Galactibolt, Space Meds, Star Supplies, HypeShield, Gigablaster, and Growton Torpedo.
- 🎮 **3 Game Modes:**
  - **Learning Mode:** Guided hints showing the exact tool required next.
  - **Practice Mode:** Train your memory without hints.
  - **Exam Mode:** Blind test with completely hidden sequence cards.
- 🔊 **8-Bit Web Audio Synthesizer:** Real-time sci-fi laser sound effects, warp chimes, error buzzers, and victory fanfare (toggleable).
- 🌌 **Twinkling Starfield Animation:** Hyperspace starry particle canvas running smoothly in the background.
- 🔍 **Instant Mission Search:** Search across all 40+ Startopia missions by keyword.
- 📊 **Detailed Captain Stats:** Tracks completed voyages, streak records, mistake counters, and accuracy ratings.
- 📱 **Mobile Optimized:** Fully playable on smartphones with touch-friendly layout and pixel font scaling.
