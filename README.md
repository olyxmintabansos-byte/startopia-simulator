> **Simulator Misi & Pelatih Refleks Kapten Startopia Growtopia Interaktif Berbasis Pixel Art — Kuasai Urutan 12 Star Tool, Uji Hafalan Tanpa Hint, dan Hindari Kehilangan Kapal Luar Angkasa.**

Dalam ekspedisi **Startopia** di game Growtopia, satu kesalahan kecil dalam memilih alat keselamatan (*Star Tool*) dapat berakibat fatal: hilangnya kapal, habisnya bekal, dan kerugian ratusan World Locks. **Startopia Mission Trainer** menghadirkan simulasi berbasis browser otentik dengan grafis pixel-art retro dan synthesizer efek suara 8-bit untuk melatih memori otot para kapten.

## ✨ Fitur Utama

- 🛸 **12 Star Tools Lengkap:** Dilengkapi ikon dan nama resmi seluruh alat misi antariksa Growtopia.
- 🎮 **3 Mode Pelatihan:**
  - 🟢 **Learning Mode:** Mode panduan dengan petunjuk visual alat yang harus ditekan selanjutnya.
  - 🟡 **Practice Mode:** Latihan tanpa petunjuk, menampilkan notifikasi kesalahan seketika.
  - 🔴 **Exam Mode:** Ujian buta (*blind test*) dengan kartu urutan alat tertutup untuk menguji hafalan absolut.
- 🔊 **8-Bit Web Audio Synthesizer:** Generator efek suara murni via Web Audio API (suara tembakan laser, dengung warp drive, buzzer kesalahan, dan nada kemenangan fanfare).
- 🌌 **Twinkling Starfield Particle Canvas:** Latar belakang luar angkasa dengan animasi bintang berkedip dinamis berkecepatan 60 FPS.
- 🔍 **Instant Mission Search:** Mesin pencari instan untuk menemukan solusi dari 40+ misi Startopia berdasarkan kata kunci ancaman atau nama musuh alien.
- 📊 **Statistik Kapten:** Melacak jumlah ekspedisi berhasil (*completed voyages*), rekor streak terpanjang, counter kesalahan, dan persentase akurasi.
